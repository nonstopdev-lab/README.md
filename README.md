## How we work

1. **Tell us the goal.** A short message or a call. We say plainly if we are not the right fit.
2. **Get a plan and a price.** A written scope, a timeline and a fixed price or estimate before any work starts.
3. **We build and run it.** Short cycles you can review. Telegram work goes live with proof of every placement.

## Principles

- **Build what works, then polish.** A working version in your hands beats a perfect plan on paper.
- **Automate the repetitive.** If a task repeats, software should do it.
- **Honest numbers, real people.** We report what actually happened, and we say so when something did not work.
- **You own what we build.** For custom work you receive the source code and documentation. No lock-in, no surprises.
